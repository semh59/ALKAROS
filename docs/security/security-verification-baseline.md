OWASP ASVS and its cheat sheets are verification guidance. They do not by
themselves select JWT, mTLS, TLS minimum, scanning cadence or a target ASVS
level for this product. The former unapproved defaults are withdrawn.

The replacement baseline requires a documented threat model, selected ASVS
requirement IDs with applicability rationale, verification method, named
security approver and downstream owner for every control.
