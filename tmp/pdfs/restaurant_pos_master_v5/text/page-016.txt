I.22 RecipeVersion → ProductionBatch Immutable
Rule
Bu kural kesinlikle zorunludur. ProductionBatch.RecipeVersionId
production gerçekleştiğinde immutable historical reference olur.
Recipe v1: Chicken = 180g
Recipe v2: Chicken = 160g
ProductionBatch #1001 →  RecipeVersionId = v1
ProductionBatch #1027 →  RecipeVersionId = v2
Reçete daha sonra değişse bile #1001 v1'e göre kalır.
I.22.1 Historical cost
ProductionBatch ayrıca geçmiş maliyet hesabının yeniden üretilebilmesini
sağlayacak gerekli snapshot/reference verisini korur (bkz. III.12.5
recipe_cost_snapshots).
I.23 V1.1 — Portion Inventory
Canonical state list: II.5.6.
Reserved, Released, Consumed, Waste
(Available bir stok-havuzu koşuludur, reservation lifecycle state'i değildir
— bkz. II.5.6 notu.)
I.23.1 Akış
Available →  Reserved →  Consumed
Reserved →  Released →  Available   (cancellation)
Consumed →  Waste                  (hazırlanmış ürün, 
satılabilir stoğa geri dönmez)
