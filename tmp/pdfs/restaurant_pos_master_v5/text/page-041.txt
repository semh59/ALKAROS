gap B4.3)
Queued, Preparing, Ready, Served, Cancelled
A distinct, finer-grained state machine from KitchenTicket (II.5.7) — a
single ticket can have some items Ready and others still Preparing.
Extends the existing rule (II.8.4: "Order state and kitchen ticket state are
separate") one level deeper: ticket-item state and ticket state are also
separate. The parent ticket only reaches Ready when all non-cancelled
items are Ready or Served. → III.16.5 kitchen_ticket_items.status
