I.16 V1 — Kitchen State
Order state ile kitchen state aynı değildir.
Order = Accepted
KitchenItem A = Ready
KitchenItem B = Preparing
KitchenItem C = Cancelled
Bu nedenle Order, OrderItem, KitchenTicket, KitchenTicketItem ayrı
kavramlardır. Ek olarak (bu master belgede yeni netleştirilen):
KitchenTicket ile KitchenTicketItem de birbirinden ayrı, kendi state
machine'lerine sahiptir — bkz. II.5.7 ve III.16.5 (Corrections v5 §4.3).
I.16.1 Printer routing

Routing menu/product configuration üzerinden yapılır.
