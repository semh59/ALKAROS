III.1 Database design principles
III.1.1 One PostgreSQL database, logical schemas per bounded
context
identity, catalog, table_mgmt, orders, billing, payments, cash, 
menu, recipe,
production, inventory, purchasing, kitchen, meal_card, 
customer_account,
fiscal, invoicing, qr, online_ordering, reporting, audit, 
reconciliation,
backup, licensing, settings, observability
Single database, single deployment.
III.1.2 English names only
All tables, columns, indexes, constraints, views, functions, jobs, enums, and
migration names must be English.
III.1.3 Primary keys
uuid primary keys for all core tables; naming convention {table}_id.
III.1.4 Timestamps
UTC. Recommended: created_at, updated_at, created_by, updated_by,
deleted_at only where soft delete is explicitly allowed.
III.1.5 Money
All monetary values use numeric. numeric(18,2) for money;
numeric(18,3)/numeric(18,4) for weights/quantities. Never float/double
for money.
III.1.6 Optimistic concurrency
row_version bigint not null default 1 or equivalent concurrency
token.
