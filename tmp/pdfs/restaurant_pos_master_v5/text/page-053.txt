Important tables should either be immutable or fully auditable with history
tables and event records.
III.1.8 No destructive silent delete
Transactional records must not be hard-deleted in normal operation.
III.2 Shared column conventions
{entity}_id uuid primary key
business_id uuid not null where multi-business readiness matters
status text not null
created_at timestamptz not null
updated_at timestamptz not null
created_by uuid null
updated_by uuid null
row_version bigint not null default 1
For immutable history tables, updated_at may remain same as
created_at or be omitted where sensible.
III.3 Identity schema
III.3.1 users
identity.users: user_id PK, username unique not null, password_hash not
null, display_name not null, email null, phone null, active bool default true,
last_login_at null, created_at, updated_at, row_version.
Constraints: username unique; only active users may log in. Indexes:
unique(username), index(active).
III.3.2 roles
identity.roles: role_id PK, code unique not null, name not null, active
default true.
Examples: Owner, Manager, Cashier, Waiter, Kitchen, Accountant.
