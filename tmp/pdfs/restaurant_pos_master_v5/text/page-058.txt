III.7 Bill schema
III.7.1 bills
billing.bills: bill_id PK, bill_number unique not null, table_id FK
nullable, order_id FK nullable, customer_account_id nullable, status not null,
subtotal default 0, discount_total default 0, tax_total default 0,
payable_amount default 0, allocated_amount default 0, paid_amount
default 0, change_amount default 0, currency_code char(3) default 'TRY',
opened_at not null, closed_at null, cancelled_at null, row_version.
Derived-field contract (authoritative — matches II.6.5):
allocated_amount = SUM(valid
payment_allocations.allocated_amount) for this Bill.
paid_amount = SUM allocation amounts belonging to payments that
are financially final and not subsequently reversed/refunded.
change_amount = SUM actual cash change returned for the Bill.
These fields are cached projections for operational reads;
allocation/payment rows remain the authoritative ledger.
Application transactions must update the cached values atomically with
the corresponding payment/allocation mutation.
