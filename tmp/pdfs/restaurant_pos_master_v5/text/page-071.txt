III.18 Customer Account schema
III.18.1 customers
customer_account.customers: customer_id PK, code unique not null,
customer_type not null, display_name not null, tax_number null, tax_office
null, email null, phone null, address_line null, city null, country_code char(2)
default 'TR', e_invoice_registered default false, active default true,
retention_until date null, anonymization_status text not null default
'Active', anonymized_at timestamptz null, deletion_requested_at
timestamptz null, created_at, updated_at, row_version.
Canonical anonymization_status: Active, AnonymizationPending,
Anonymized, RetentionBlocked.
III.18.2 customer_accounts
customer_account.customer_accounts: customer_account_id PK,
customer_id FK not null, account_number unique not null, status not null,
opening_balance default 0, current_balance default 0, payment_terms_days
default 0, retention_until date null, anonymization_status text not null
default 'Active', anonymized_at timestamptz null, created_at, row_version.
Canonical anonymization_status: Active, AnonymizationPending,
Anonymized, RetentionBlocked.
III.18.3 account_transactions — CORRECTED (Corrections v5
§4.4, closes audit finding B4.4)
customer_account.account_transactions: account_transaction_id PK,
customer_account_id FK not null, transaction_type not null, amount not
null, bill_id FK nullable, invoice_id FK nullable, note null, created_at not null,
created_by null.
Canonical transaction_type: Charge, Payment, Invoice, Credit,
Debit, Adjustment, Refund.
direction is a generated column, not independently writable (previously
risked drifting out of sync with transaction_type if stored as an ordinary
column):
alter table customer_account.account_transactions
    add column direction text
