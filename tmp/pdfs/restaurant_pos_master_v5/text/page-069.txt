not null, status not null, attempt_count default 0, last_error null, created_at

schema with no defined list — now added, matches II.5.8 exactly):
Pending
Printing
Printed
Failed
Retrying
Cancelled
Rules: Failed does not delete the parent kitchen_ticket_id / order_id;
Retrying increments attempt_count, and idempotency_key prevents
uncontrolled duplicate physical output on retry; Cancelled is only
reachable from Pending or Retrying, never from Printed.
