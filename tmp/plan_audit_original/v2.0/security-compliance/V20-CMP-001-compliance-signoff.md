# V20-CMP-001 - Obtain compliance sign-off

- Status: Planned
- Assignee: Unassigned (exactly one person)
- Work type: validation

## Goal

Collect named, dated approval that the implemented release matches the verified fiscal, invoicing, retention and privacy applicability decisions.

## Owned surface

- `release/evidence/compliance/**`
- Bu görev mevzuat yorumu üretmez veya ürün kodunu değiştiremez.

## In scope

- Decision-to-implementation evidence, reviewer identity/authority, open exception register and approval expiry/conditions.

## Out of scope

- Self-approving legal interpretations, integration implementation and production rollout.

## Dependencies

- V0-CMP-001, V0-CMP-003, V12-FSC-003, V15-KVK-001, V15-KVK-002, V20-INT-001, V20-INT-002

## Deliverables

- Signed compliance matrix and exception register.

## Acceptance evidence

- Every applicable obligation has named approval and implementation evidence; any unresolved or expired approval blocks the gate.
