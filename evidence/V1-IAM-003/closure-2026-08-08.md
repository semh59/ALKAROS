## Design özeti

- Ham token yalnız `Create()` dönüşünde; veritabanında yalnızca SHA-256 hex hash (`token_hash VARCHAR(64) UNIQUE`).
- Authenticate: hash eşleşmesi + user/device bağı + revoked + expired kontrolleri; geçerliyse `last_seen_at` dokunulur.
- Reconnect: yalnızca işlenmemiş `session_operations` (operation_id PK üzerinden dedup) `queued_at` sırasıyla uygulanır.
- Revoke: session bazlı tek kayıt; `RevokeDeviceAsync` aynı user+device'ın tüm oturumlarını iptal eder.
- DB FK: `device_sessions.user_id -> users(user_id) ON DELETE CASCADE`; migration 009 down: tablolar hazardı sırasıyla
  düşer.
