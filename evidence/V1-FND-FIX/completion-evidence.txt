1. Fixes applied
----------------
- src/BuildingBlocks/Messaging/RetryPolicy.cs: RecordFailureAsync now takes
  NpgsqlConnection + optional NpgsqlTransaction (join the claim transaction)
  instead of NpgsqlDataSource; parameterised UPDATE unchanged.
- src/BuildingBlocks/Messaging/OutboxStore.cs and InboxStore.cs: claim
  (SELECT ... FOR UPDATE SKIP LOCKED), delivery and state transitions now
  run in a single transaction committed after all marks. Previously the
  claim lock dropped when the reader closed, so a concurrent dispatcher
  could re-claim the same pending messages and deliver them twice
  (reproduced as DispatchConcurrentDispatchersDeliverEachMessageOnce
  delivering 12 instead of 8, and the inbox equivalent).
- src/BuildingBlocks/TransactionOutboxIntegration/TransactionOutboxResource.cs:
  CommitAsync writes all buffered envelopes in one multi-row INSERT batch
  (single command, single commit) instead of one command per envelope;
  CultureInfo.InvariantCulture on the interpolated placeholder append
  (CA1305).
- src/Host/ALKAROS.Host.csproj: OutputType Library -> Exe (the host is an
  executable entry point).
- tests/BuildingBlocks/TestHelpers: new shared project (PgTestDatabase base
  fixture, RecordingResource, SimulatedFailures/FixedClassifier) that the
  Idempotency, Transactions and TransactionOutboxIntegration test projects
  reference; duplicated fixtures removed.
- ALKAROS.slnx, build/project-manifest.json: TestHelpers registered.
- plan/v1/foundation/V1-FND-006-transaction-outbox-integration.md:
  Surface state Implemented -> Existing (only legal values are
  Planned/Existing; validation error fixed).
