V1-FND-005 acceptance coverage:
- Join behavior propagates into the ambient transaction; the inner call
  does not commit independently (Propagation: 3 tests).
- CreateNew inside an active scope is rejected with
  NestedTransactionException and rolls back the outer scope; CreateNew
  without ambient starts a root (Propagation: 2 tests).
- Workflow failure rolls back every enlisted resource in reverse commit
  order and the original exception is rethrown unchanged (Execution).
- Commit failure rolls back already-committed resources too; journal:
  first:committed, second:commit-failed, third:rolled-back,
  second:rolled-back, first:rolled-back (Execution).
- Rollback failure surfaces TransactionExecutionException with
  AggregateException(original, rollback) (Execution).
- Unknown failures are never retried (1 attempt with MaxAttempts 5);
  only ITransientFailure (including inner exceptions) is retried; every
  retry runs on a fresh scope; attempts are exhausted by 3; default
  policy never retries (Retry: 8 tests).
- Retry delay receives completed-attempt numbers 1, 2 (Retry).
- Invalid options/arguments are rejected: MaxAttempts 0, JoinBehavior
  out of range, null workflow/enlist (Execution + Retry).
- Cancellation propagates: OperationCanceledException surfaces with the
  caller token, resources rolled back, no retry on cancellation (Execution).
- Concurrent root transactions are isolated: ambient state does not leak
  between parallel flows (16 parallel roots + nested joins) (Concurrency: 3 tests).
